### Web Science 2024: Team 2's Final Project
# RP League

## Introduction
Rensselaer Polytechnic League gives students the fun experience of managing sports leagues and curating their very own roster for RPI and using our very own RPI athletes. The goal is to promote interest in RPI athletics amongst the students, bring fantasy leagues to the college sphere, and have fun with friends!

## Installation
Please refer to install.md for detailed instructions on how to install and run the project locally.

## Features
- NO MONETARY, GAMBLING OR ANYTHING OF REAL VALUE REWARD INCLUDED.
- Create and manage your own sports league
- Draft players from RPI's sports teams
- View leaderboards for both your league and the entire platform

## While developing the project...
- We used the MERN stack (MongoDB, Express, React, Node.js) to build the project.
- Figma was used to design the UI/UX of the project.
- Porting to React.js from vanilla HTML/CSS/JS was a challenge, but we learned a lot about the benefits of using a front-end framework.
We have to break up huge HTML and CSS files into smaller components, combine them into parent components, and pass data between them.
- For the user system, we originally planned to use Firebase, but we switched to MongoDB for the sake of easier integration and more control over the data.
- This is a highly complicated project, and we are glad that we have a well-thought-out info architecture and design as a strong foundation. We really enforced
the importance of proper organization and naming habits, which made the project much easier to manage.
- Aside from the project itself, Github was also used to a certain depth, as we have to resolve several multi-file merge conflicts and learn how to use Git effectively in a team environment,
enhancing our understanding of and the ability to use Version Control Systems.
